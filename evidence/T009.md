## Failure / decision tests (synthetic; not native evidence)
- First-session win + confirmation loss → no promotion; incumbent preserved
- Two winning sessions → accepted
- Duplicate/stale/missing evidence → rejection
- Crash/timeout → incumbent preserved
- Interrupted search → resume continues
- All lose → stopped with `accepted: null`
- Resume smoke/protocol mismatch → RuntimeError
